# Tuned optima — retrodiction target set for the knob planner (Stage A)

This file is the ground-truth target set for Stage A of the knob planner: every plotted
frontier ("ours") point per dataset, with the exact tuned knob string that produced it.
The planner is scored on how well it retrodicts these knobs from (dataset, target recall band).
Knob strings are preserved verbatim from the provenance audit; the only alteration is that
literal `|` characters inside knob/source strings are escaped as `\|` for markdown-table safety.
Rows with unrecoverable or inferred knob values are flagged inline (UNKNOWN / INFERRED).

Totals: 108 rows — wiki-35M 14, DEEP-10M 21, WebVid-2.5M 14, msturing30m 8, cohere 12 (6 x 1M + 6 x 10M), text2image 39 (16 x 1M + 18 x 10M + 5 x 100M).
